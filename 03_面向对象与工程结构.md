## 题目 1：dataclass 建模

定义 `Product`，字段：`sku: str`、`price: Decimal`、`stock: int`；初始化时保证价格和库存非负。

### 参考答案

```python
from dataclasses import dataclass
from decimal import Decimal

@dataclass(slots=True)
class Product:
    sku: str
    price: Decimal
    stock: int

    def __post_init__(self) -> None:
        if self.price < 0 or self.stock < 0:
            raise ValueError("价格和库存不能为负")

product = Product("SKU-1", Decimal("19.90"), 5)
assert product.price == Decimal("19.90")
```

## 题目 2：业务逻辑与异常

实现 `InventoryService.reserve(sku, quantity)`，合法请求扣减库存；数量 <= 0、SKU 不存在、库存不足时分别抛出明确异常。要求业务操作集中在 Service 中。

### 参考答案

```python
class InventoryError(Exception):
    pass

class InventoryService:
    def __init__(self, stock: dict[str, int]) -> None:
        self._stock = stock.copy()

    def reserve(self, sku: str, quantity: int) -> int:
        if quantity <= 0:
            raise ValueError("quantity 必须大于 0")
        if sku not in self._stock:
            raise KeyError(sku)
        if self._stock[sku] < quantity:
            raise InventoryError("库存不足")
        self._stock[sku] -= quantity
        return self._stock[sku]

svc = InventoryService({"A": 5})
assert svc.reserve("A", 2) == 3
```

**重要**：此代码仅适合内存练习，不具备跨进程并发扣库存的原子性。生产环境应使用数据库条件更新/事务等机制。

## 题目 3：Protocol 与依赖注入

编写 `UserRepository` 协议以及内存实现，并让 `UserService` 依赖协议而不是具体存储。

### 参考答案

```python
from typing import Protocol

class UserRepository(Protocol):
    def find_name(self, user_id: int) -> str | None: ...

class InMemoryUserRepository:
    def __init__(self, users: dict[int, str]) -> None:
        self.users = users

    def find_name(self, user_id: int) -> str | None:
        return self.users.get(user_id)

class UserService:
    def __init__(self, repository: UserRepository) -> None:
        self.repository = repository

    def get_display_name(self, user_id: int) -> str:
        return self.repository.find_name(user_id) or "未知用户"

assert UserService(InMemoryUserRepository({1: "张三"})).get_display_name(1) == "张三"
```

**Java 对照**：`Protocol` 提供结构化类型约束，不必像 Java 接口那样声明 `implements`。

## 题目 4：模块、包与配置

将服务拆成包，并用环境变量读取应用配置。写出目录结构、`pyproject.toml` 和最小配置模块。

### 参考答案

```text
myapp/
├── pyproject.toml
├── src/
│   └── myapp/
│       ├── __init__.py
│       ├── config.py
│       ├── domain.py
│       ├── repository.py
│       └── service.py
└── tests/
    └── test_service.py
```

`pyproject.toml`：

```toml
[build-system]
requires = ["setuptools>=68"]
build-backend = "setuptools.build_meta"

[project]
name = "myapp"
version = "0.1.0"
requires-python = ">=3.11"

[tool.setuptools.packages.find]
where = ["src"]
```

`src/myapp/config.py`：

```python
from dataclasses import dataclass
from os import getenv

@dataclass(frozen=True)
class Settings:
    database_url: str
    debug: bool

    @classmethod
    def from_env(cls) -> "Settings":
        return cls(
            database_url=getenv("DATABASE_URL", "sqlite:///local.db"),
            debug=getenv("DEBUG", "false").lower() == "true",
        )
```

安装与验证：`python -m pip install -e .`，然后 `python -c "from myapp.config import Settings; print(Settings.from_env())"`。

## 题目 5：pytest 单元测试

对题目 2 的库存服务编写成功、失败两个测试。把题目 2 的代码放到 `src/myapp/service.py`，在 `tests/test_service.py` 写测试。

### 参考答案

```python
import pytest
from myapp.service import InventoryError, InventoryService

def test_reserve_success():
    svc = InventoryService({"A": 5})
    assert svc.reserve("A", 2) == 3

def test_insufficient_stock():
    svc = InventoryService({"A": 1})
    with pytest.raises(InventoryError, match="库存不足"):
        svc.reserve("A", 2)
```

安装 `python -m pip install pytest`；执行 `python -m pytest -q`。
